# Kids 3D Learning Universe

Kids 3D Learning Universe is a colorful 3D-style kids learning website where parents can curate YouTube educational videos in one place.

## Features

- 3D animated cube hero section
- Parent-curated YouTube video library
- Filters by category, age, and language
- Search bar
- Responsive design
- GitHub Pages ready
- Easy video updates through `videos.js`

## Deploy to GitHub Pages

1. Create a GitHub repository named `kids-3d-learning-universe`
2. Upload all files
3. Go to Settings > Pages
4. Select Deploy from branch
5. Select `main` and `/root`
6. Save

Your live link will look like:

```text
https://sushmasushma1233.github.io/kids-3d-learning-universe/
```
