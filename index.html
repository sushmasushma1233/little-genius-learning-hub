How to Add More YouTube Videos

Open videos.js, copy one object, change title and YouTube ID, then commit changes in GitHub.

1

Copy YouTube Link

Example: https://youtu.be/mbPNkDEN3Ps

2

Take Video ID

Video ID is the part after youtu.be/ or after watch?v=

3

Paste in videos.js

Add category, age, language, and description.

{
  title: "Kids Learning Video",
  youtubeId: "mbPNkDEN3Ps",
  age: "2-4",
  category: "Rhymes",
  audience: "Both",
  language: "English",
  description: "Educational video for kids."
}
